공작기계지능화실험실 제조 DB 시스템을 이 PC 에 설치합니다.
인터넷이 없어도 설치됩니다. 필요한 프로그램은 모두 이 설치 파일 안에 들어 있습니다.

[ 설치되는 것 ]
  · 제조 DB 프로그램 (컨트롤러 · 웹 대시보드 · 수집기 · 관리 도구)
  · 전용 파이썬 3.14 런타임 — 이 PC 에 파이썬이 없어도 됩니다. 설치된 다른 파이썬과 섞이지 않습니다.
  · MySQL 8.0 (선택) — 'OrcusMySQL' 이라는 Windows 서비스로 등록되어 부팅 때 자동으로 켜집니다.
    이 PC 에 이미 MySQL 8.0.16 이상이 있으면 그것을 대신 쓸 수도 있습니다.
  · Microsoft Visual C++ 재배포 패키지 (MySQL 이 사용, 없거나 오래된 경우에만)

[ 설치 중에 하는 일 ]
  · 데이터베이스(orcus)와 테이블을 만들고 기본 공구 목록을 넣습니다.
  · 원본 백업 보관소(archive_vault) 폴더를 만듭니다.
  · (선택) 다른 PC 에서 대시보드(포트 8501)에 접속할 수 있도록 Windows 방화벽을 엽니다.
  · 바탕 화면과 시작 메뉴에 '제조 DB Controller' 바로 가기를 만듭니다.

[ 알아 둘 것 ]
  · 설치 폴더와 데이터 폴더는 영문 경로여야 합니다 (MySQL 제약). 기본값: D:\ManufacturingDB, D:\Orcus
    (D 드라이브가 없으면 C 드라이브)
  · MySQL root 비밀번호의 기본값은 610610610 입니다. 설치 화면에서 바꿀 수 있습니다.
  · 프로그램을 제거해도 원본 백업 보관소는 지우지 않습니다. 데이터베이스 파일은 제거할 때 지울지 묻습니다.
  · 같은 설치 파일(또는 새 판)을 다시 실행하면 데이터와 설정을 그대로 둔 채 프로그램만 바꿉니다.
  · 서명되지 않은 설치 파일이라 Windows SmartScreen 이 경고하면 '추가 정보' → '실행' 을 누르세요.
